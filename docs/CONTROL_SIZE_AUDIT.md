## 修复的问题

- 复制、配置等旧操作只有52px高，小尺寸时仅36px，现统一为76px。
- 语音按钮原有图标小、外侧空隙大；改用32px明确状态图标，减小间隙。
- 原生 List 的 itemscale 会把标题与边缘行缩小。现统一关闭自动缩放，
  使用固定标题、独立滚动区域、末尾留白和圆弧渐隐。
- 服务页旧高优先级 padding 导致首行和固定标题重叠；已消除。
- 语音球遮盖状态文字、提示条覆盖语音控制；已调整。
- 标签原文选中后文字颜色未同步，开关类名可能残留旧状态；改用明确绑定。
- 录音状态灯改为直接绑定状态颜色；聊天主次操作统一居中宽度。

## 手势容器修正

实机显式up/down与原生Swiper同时响应时，会产生两页之间的残余偏移。
最终移除原生Swiper拖动容器，四个主菜单按pageIndex条件渲染；根手势只处理
up/down，left/right不改变主菜单。29–32是中间诊断版本，不作为最终通过证据。

补充：主菜单拦截系统Back，不再因系统右滑Back退回上一主菜单；子页Back
仍按父级返回，硬件Home/表冠仍可离开应用。列表滚动与菜单手势通过scroll事件
仲裁；`swipe` 只记录待切换页，手指抬起时立即挂载，避免旧手势带偏新列表，
同时不再使用固定 220ms 延迟。
最终源码39、核心14、API8 81，共134项。36–39包含系统返回桌面造成的诊断画面，
不能用于宣称最终菜单循环通过。
