# 视觉设计系统

## 1. 风格方向

以 watchOS 的圆润、克制、信息分层为参考，结合 NOVA 的蓝色玻璃语音球。此项目是独立设计探索，不是 Apple 官方界面或资产复刻。

## 2. 色彩

核心 Token 在 `assets/tokens.json`。

| Token | 色值 | 用途 |
|---|---|---|
| Background | `#05070B` | 主背景与表盘外区域 |
| Surface | `#10141C` | 深色表面 |
| Surface Raised | `#1B2230` | 浮层、气泡、控件 |
| Text Primary | `#F4F7FC` | 主要文字 |
| Text Secondary | `#A4B0C3` | 次要文字 |
| Blue | `#287CFF` | 主操作与选中态 |
| Blue Bright | `#5BCBFF` | 高光与语音反馈 |
| Violet | `#826BFF` | 可选辅助强调色 |
| Mint | `#24D7AB` | 成功/完成态 |
| Record Red | `#FF4262` | 停止录音/结束语音 |
| Amber | `#FFB44A` | 轻量强调 |

## 3. 字体层级

字体栈优先系统字体：`-apple-system, BlinkMacSystemFont, SF Pro Display, SF Pro Text, PingFang SC, Microsoft YaHei, sans-serif`。

- 微型状态：9 px，仅用于表盘时间、状态标签等非主要内容
- 辅助说明：11 px
- 正文：13 px
- 强调正文：15 px
- 小标题：17 px
- 桌面演示标题：24 px 及以上

圆屏聊天内容优先保证可读性；如长文本过多，使用滚动，不要压缩到极小字号。

## 4. 圆屏布局

- 表圈与内容边缘之间保留安全距离。
- 重要操作集中在中部 70–80% 直径区域。
- 顶部时间/标题避开表盘最上方弧线。
- 底部输入框、发送按钮与挂断按钮不贴近圆弧。
- 长列表区域采用内部滚动，避免整体页面被撑开。

## 5. 组件规范

### 主操作
- 蓝色渐变、轻微高光、薄描边。
- 使用较强对比度；按下时轻微缩放（约 0.92–0.97）。

### 次操作
- 深灰玻璃表面，边框低对比。
- 避免每个按钮都使用高饱和色。

### 消息气泡
- 用户消息靠右、助手消息靠左。
- 圆角约 13–18 px；保留细边框和柔和阴影。
- 文本按字词换行，不能依赖固定高度裁切。

### 录音/语音状态
- 语音球使用蓝色多层渐变和柔和外发光。
- 录音停止控件使用红色渐变，与蓝色主操作形成语义区分。
- 动态波形仅表达状态，不承担唯一信息传达；同时显示状态文字。

## 6. 动效规范

- 控件按压：约 180–240 ms
- 页面过渡：约 300–380 ms
- 语音球循环：约 4.5–5.5 s，低频、柔和
- 波形：错峰动画，避免全体同步跳动
- `prefers-reduced-motion: reduce` 时停用循环动效或缩短至近乎瞬时

## 7. 美术资产

可在 `asset-gallery.html` 预览；可编辑 SVG 位于 `assets/brand/`、`assets/illustrations/` 和 `assets/icons/`。统一图标采用 24×24 viewBox、约 1.8 px 线宽、圆头线帽和圆角连接。
