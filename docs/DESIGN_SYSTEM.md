# 视觉设计系统

## 1. 方向

Aurora Watch 以深黑玻璃、青色能量球和高对比中文信息层级为核心。
视觉参考用户提供的 ChatGPT 手表概念图，但页面结构只保留本产品实际
需要的语音、录音、任务、历史、聊天和服务配置。

## 2. 色彩

Web 原型 Token 位于 `prototypes/aurora-watch/styles.css`：

| Token | 色值 | 用途 |
|---|---|---|
| `--page` | `#040607` | 页面底色 |
| `--cyan` | `#45e9ff` | 主高光、语音环、主按钮 |
| `--cyan-bright` | `#9afaff` | 高亮文字和焦点 |
| `--teal` | `#23f3cc` | 成功、完成、能量球辅助色 |
| `--blue` | `#34a7ff` | 次入口和链接感操作 |
| `--danger` | `#ff5d70` | 停止录音、危险动作 |
| `--text` | `#f4fbfc` | 主文字 |
| `--muted` | `#8497a1` | 次要说明 |
| `--dim` | `#4f626d` | 最低层级状态 |

API 8 工程使用等效的不透明/渐变值，避免依赖 Web 的 `backdrop-filter`。

## 3. 字体

```text
"Noto Sans SC", "HarmonyOS Sans SC", "SF Pro Display",
"Segoe UI Variable Display", "PingFang SC", "Microsoft YaHei UI", sans-serif
```

- 页面标题：24–27 px。
- 列表主文：14–16 px。
- 列表次文：9–11 px。
- 微型状态和页脚：7.5–9 px。
- 圆屏正文优先滚动，不通过无限缩小字号塞入。

## 4. 圆屏安全区

- 页面核心内容限制在直径约 80% 的中央区域。
- 底部输入框、按钮和列表末项避开圆弧。
- 列表使用内部滚动和底部留白。
- 466 × 466 是设备设计坐标；小尺寸通过 designWidth 等比缩放。

## 5. 组件

### 主按钮

- 青色/蓝色渐变，圆角胶囊。
- 细描边、内高光、柔和外发光。
- 高度 44–54 px。

### 玻璃列表行

- 深色半透明底、低对比描边。
- 左侧图标盒，中间标题/副标题，右侧状态或箭头。
- 高度约 52–62 px，行间 8–12 px。

### 语音能量球

- 透明底位图叠加深色发光层。
- 中心保持高亮，外围降低亮度。
- 不做会与录音波形抢焦点的循环粒子。

### 录音控制

- 主录音环使用青色，结束按钮使用红色。
- 波形中部高、两侧低。
- 状态文字同时表达录音/暂停，不只依赖颜色。

### 消息气泡

- 用户消息蓝色玻璃，助手消息深青灰玻璃。
- 文本自然换行，长内容滚动。
- 聊天底栏居中，输入框和发送按钮都留在安全区。

## 6. 动效

- 控件按压：180–240 ms。
- 页面切换：300–380 ms。
- 语音环呼吸：2–3 s。
- 录音波形错峰滚动。
- 系统减少动态效果时停止循环动画。
