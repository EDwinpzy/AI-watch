# NOVA Watch AI v1.2.0

首版静音手表 AI 助手，面向 HUAWEI WATCH 4 / HarmonyOS API 8。

## 主要能力

- 首页能量球与“开始对话 / 录音摘要”双入口。
- 语音输入、录音暂停/继续/标记、文字聊天和最近任务。
- 录音结束后由 PC 服务完成 Whisper 转写，再创建只读 Codex 异步任务。
- 1.5 秒轮询、长任务续查、停止任务和后端不可用快速失败。
- 服务地址、访问令牌、模型和只读仓库配置。
- 圆屏手势导航：主页面上下切换，子页左滑返回，无可见返回按钮。

## 静音与交互

- 手表端不导入音频播放模块，不下载或播放 TTS 文件。
- Codex 任务只返回文字，`audioUrl` 固定为空。
- 录音、转写、任务完成、失败和取消都不播放提示音。
- 系统侧可配合免打扰和音量归零使用，不影响睡眠。

## 安全边界

- Codex 路由使用 `X-Nova-Token` 或 Bearer Token。
- 仓库只能由 PC 服务端 allowlist 指定。
- 第一版固定只读沙箱，不允许手表修改代码。
- 明文 HTTP 仅用于可信局域网。

## 验证

- 后端单元测试 12 项通过。
- 源码、核心前端和 API 8 共 128 项检查通过。
- 真实文字任务超过 60 秒仍可轮询。
- 并发保护返回 HTTP `409`；取消后子进程退出。
- 真实 PCM 语音创建耗时 2.72 秒，转写正确，无 TTS 输出。
