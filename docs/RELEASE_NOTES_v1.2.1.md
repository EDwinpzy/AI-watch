# NOVA Watch AI v1.2.1

手表语音手势与 PC Codex 任务桥的修复版本，继续面向 HUAWEI WATCH 4 /
HarmonyOS API 8，并保持全程静音。

## 修复

- 进入语音页不再自动申请麦克风或开始录音。
- 按住语音球开始采集；松开发送，上滑至少 28 px 后松开结束。
- 触摸被系统中断时取消本次输入，不提交残缺音频。
- 修复嵌套 `codex exec` 继承桌面端 Core 沙箱环境标记后无法执行只读工具的问题。
- 子进程启动前移除桌面端 Core 沙箱标记；取消和超时仍会结束整个任务进程树。
- 本机签名配置移出 Git 跟踪，只保留无凭据模板；构建脚本拒绝已跟踪的签名配置。

## 保持不变的边界

- 手表不播放 TTS、提示音或其他音频，`audioUrl` 始终为空。
- 主页面上下滑切换，子页左滑返回，不显示返回或关闭按钮。
- Codex 任务继续使用令牌鉴权、仓库白名单、单任务并发和只读沙箱。
