# 产品规格

## 1. 产品定位

NOVA Watch AI 是圆形手表上的静音 AI 工作助手。用户用语音或文字提出
问题，由 PC 本地服务完成转写和只读 Codex 分析，手表显示结果。

## 2. 设计原则

1. **静音优先**：手表永不播放 TTS、提示音或媒体。
2. **一屏一主任务**：首页只保留语音和录音摘要两个入口。
3. **手势导航**：不显示返回、关闭或取消导航按钮。
4. **圆屏安全区**：标题、列表和底部操作避开圆弧裁切。
5. **异步长任务**：避免旧 API 8 `@system.fetch` 窗口造成假成功，统一使用
   `@ohos.net.http`。
6. **只读优先**：第一版分析仓库但不修改文件。
7. **双界面同能力**：经典 Aurora 与 Apple Watch 圆环界面都覆盖语音、
   录音摘要、异步任务、历史和结果操作。
8. **低密度**：经典 Aurora 不绘制应用内时间/日期/信号/电池状态区，
   每页只保留一个主任务和最重要的操作。

## 3. 当前范围

### 首页

- 能量球与 ChatGPT 字标。
- 开始对话。
- 录音摘要。
- 任务运行时显示一行状态；结束后回到双入口。

### 语音与任务

- 麦克风采集 15 秒语音。
- Whisper 转写。
- 创建 Codex 只读任务。
- 1.5 秒异步轮询。
- 显示阶段、耗时、识别文本和最终结果。
- 停止任务与取消接口。

### 录音摘要

- 最长 60 秒。
- 暂停、继续、标记、结束。
- 结束后自动转写并创建 Codex 任务。
- 结果页提供摘要/转写切换、复制和继续追问。

### 历史与聊天

- 最近 Codex 任务与本地会话。
- 文字输入、发送和继续追问。
- Codex 模式与 Ollama 兼容模式。

### 设置

- 语音后端。
- 经典界面可编辑服务地址、访问令牌与只读仓库；圆环界面使用本地构建注入配置。
- 固定静音状态。
- 触感反馈。

## 4. 非目标

- VPN、节点选择、网络加速。
- 图片生成。
- 模型市场或多供应商切换。
- 推荐问题卡片。
- 手表扬声器播放。
- 手表账号、云同步和公网直连。
- 第一版写模式。

## 5. 目标环境

- HUAWEI WATCH 4 `ARC-AL00`。
- HarmonyOS 3.0 / API 8。
- 466 × 466 圆屏。
- PC 与手表位于同一可信局域网。

## 6. 成功标准

- 录音结束后 3 秒内显示任务已创建和识别文本。
- 超过 60 秒的任务仍能正常轮询。
- 停止后 PC 无残留 Codex 子进程。
- Magpie 停止时手表快速显示后端不可用。
- 手表不发出任何声音。
- 所有页面无可见返回/关闭按钮，左滑和上下滑可完成导航。
