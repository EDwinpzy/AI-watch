# 产品规格说明

## 1. 产品概述

NOVA Watch AI 是一套为圆形智能手表设计的语音优先 AI 交互概念原型。产品目标是在有限屏幕内，让用户用一次触控快速开始语音交互，并通过简化后的常规聊天、录音转写与摘要能力延续工作流。

## 2. 设计原则

1. **一屏一个主任务**：不在圆形屏幕堆叠多组工具按钮。
2. **首页直接进入语音**：点击首页语音球，在首页展示语音活动状态；不跳到通话专页。
3. **聊天使用常规气泡**：文字对话页面使用用户/助手消息气泡和底部输入框，不使用电话式布局。
4. **圆形安全区优先**：内容集中在屏幕中央，避免关键文案和触控元素落入圆弧边缘。
5. **渐进披露**：主流程保持简洁，设置页仅提供 API 设置入口。
6. **隐私优先**：正式概念不内置云端密钥；API 8 实机版通过本地/局域网测试服务验证真实麦克风与网络。

## 3. 功能范围

### P0：原型主流程
- 首页语音入口与模拟语音状态
- 常规文字聊天、模拟回复、消息列表
- 历史会话、新建会话、清空当前会话
- 录音计时、转写文本编辑、摘要生成
- API 地址、密钥、模型名称输入及格式校验
- 表盘手势导航与桌面原型导航

### 非目标
- 原始视觉原型边界；API 8 实机版已通过 PC 本地服务补充真实 ASR、模型与 TTS 验证
- 不连接真实模型服务
- 不实现真实账号认证或同步
- 不实现 VPN、代理节点、模型选择器等功能
- 不保存真实 API Key 到持久化存储

## 4. 目标环境

- 桌面浏览器：Chrome、Edge、Safari 最新稳定版本
- 触屏尺寸：圆形屏幕的 CSS 预览，常见约 320–410 px 直径
- 输入方式：点击、上下滑动、右滑返回；桌面预览额外支持键盘方向键

## 5. 成功标准

- 核心流程可以无刷新完成
- 圆屏页面不出现水平滚动或关键控件裁切
- 触控目标尽可能达到 40–44 CSS px，受表盘尺寸限制的微型状态图标除外
- 用户能区分首页语音活动和常规文字聊天
- 减少动态效果系统偏好得到尊重
