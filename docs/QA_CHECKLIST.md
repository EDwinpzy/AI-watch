# QA 与验收清单

> A–H 保留早期浏览器/Stage 原型检查项。当前 API 8 `1.2.0` 发布入口的
> 语音验收使用文末 I 节，并在 HUAWEI WATCH 4 上执行。

## A. 启动与兼容
- [ ] `index.html` 可直接打开，或可通过本地静态服务器访问。
- [ ] Chrome / Edge / Safari 当前稳定版无控制台语法错误。
- [ ] 无外部字体、CDN 或网络资源依赖。
- [ ] `asset-gallery.html` 可离线浏览所有 SVG。

## B. 圆形安全区
- [ ] 在 320、360、390、410 CSS px 预览尺寸下检查页面。
- [ ] 聊天标题、返回按钮和语音入口不触碰圆弧边缘。
- [ ] 长消息在消息列表内部滚动，不被固定高度裁切。
- [ ] 输入框与发送按钮完整可见，软键盘弹起后布局仍可用。
- [ ] 转写和摘要页不出现水平滚动。
- [ ] 设置/API 表单内容能滚动到末尾。

## C. 语音入口
- [ ] 首页点击语音球后仍留在首页并启动动效。
- [ ] 麦克风静音状态有可见反馈。
- [ ] 扬声器切换有可见反馈。
- [ ] 模拟一次对话后显示用户与助手演示内容。
- [ ] 结束语音后清理计时器并回到空闲状态。
- [ ] 上下滑动离开首页时不会留下计时器。

## D. 文字聊天
- [ ] 输入空白消息不发送。
- [ ] Enter/发送按钮可提交消息。
- [ ] 用户消息和助手回复按顺序展示。
- [ ] 新建会话后消息列表为空。
- [ ] 历史记录可以切换会话并加载对应消息。
- [ ] 清空对话只清空当前线程。
- [ ] 聊天页麦克风入口回到首页语音入口。

## E. 录音、转写与摘要
- [ ] 开始录音后计时增加。
- [ ] 停止录音进入转写页并显示演示文本。
- [ ] 编辑、保存和取消操作符合预期。
- [ ] 保存转写文本后摘要同步更新。
- [ ] 复制按钮失败时显示权限提示。
- [ ] 重新录制回到录音页并重置计时。

## F. API 设置与安全
- [ ] 保存时检查 URL/模型格式，并测试真实本地服务连接。
- [ ] 无效 URL 或空模型显示错误提示。
- [ ] 冷启动后访问密钥清空，且只存当前内存。
- [ ] 不把 API Key 写入 URL、localStorage、sessionStorage 或控制台日志。

## G. 可访问性与动效
- [ ] 键盘焦点可见。
- [ ] 按钮具有可读的 aria-label。
- [ ] 状态变化有文字提示，不只依赖颜色/动画。
- [ ] 开启系统减少动态效果时循环动效明显减少。
- [ ] 文本与背景对比度足够，触控目标尽量达到 40–44 px。

## H. 生产接入前额外验收
- [ ] 权限拒绝、断网、超时、限流、鉴权失败均有明确反馈。
- [ ] 不存在客户端生产 API Key。
- [ ] 音频上传有明确同意与删除策略。
- [ ] 模型输出安全渲染，不直接注入 HTML。
- [ ] 真实设备上测试手势冲突、滚动惯性和输入法行为。

## I. API 8 1.2.0 语音与圆形界面
- [ ] 签名 HAP 可安装并显示 `1.2.0 / versionCode 3`。
- [ ] 首次点按语音入口会弹出麦克风权限，拒绝后不崩溃且可重试。
- [ ] 16 kHz 单声道采集能启动，计时和输入电平会更新。
- [ ] 点按结束后面板依次显示转写、思考和播报状态。
- [ ] 转写文字自动成为用户消息，并触发 `group/ai-watch` 回复。
- [ ] AI 回复文字完整显示，TTS 能连续播放全部分片。
- [ ] 播报中再次点按麦克风会停止播放并开始新一轮录音。
- [ ] 设置页可关闭自动播报，关闭后回复只显示文字。
- [ ] 断网、STT 超时、TTS 失败和权限拒绝都有可读提示。
- [ ] 离开聊天页后麦克风、播放器和计时器都被释放。
- [ ] 文字输入、麦克风按钮和发送按钮在 466 圆屏上不互相遮挡。
- [ ] 软键盘弹起时输入框和发送操作仍可完成。
