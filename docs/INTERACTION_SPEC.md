# 页面与交互规格

## 1. 页面

| 页面 | 入口 | 主要动作 | 结果 |
|---|---|---|---|
| 首页 | 启动 | 开始对话 / 录音摘要 | 进入语音或录音 |
| 语音 | 首页 | 按住说话、上滑结束 | 创建语音任务或得到 Ollama 回答 |
| 语音回答 | 语音完成 | 复制、继续追问 | 进入聊天 |
| 录音摘要 | 首页 | 开始、暂停、标记、结束 | 转写并创建任务 |
| Codex 任务 | 语音/录音/文字 | 停止任务 | 取消后端任务 |
| 任务结果 | 任务成功 | 摘要/转写、复制、继续追问 | 复用文字或进入聊天 |
| 最近任务 | 主页上滑 | 打开任务/会话 | 恢复结果或聊天 |
| 文字对话 | 语音页/历史 | 输入并发送 | 创建文字任务或即时回答 |
| 设置 | 主页上滑 | 切换后端、服务、模型、触感 | 更新当前内存状态 |
| 服务配置 | 设置 | 编辑字段、保存、测试 | 保存服务地址与令牌 |
| 字段编辑 | 服务配置 | 输入、保存 | 回写单个字段 |

## 2. 主页面切换

```text
首页 ↔ 录音摘要 ↔ 最近任务 ↔ 设置
```

- 上下滑切换。
- 主页面左右滑不切页。
- 列表内部先滚动，滚到端点后上下手势才交给主菜单。

## 3. 子页导航

- 子页左滑返回父级。
- 字段编辑左滑只关闭字段编辑层。
- 首页左右滑不执行动作。
- 不渲染返回、关闭或取消导航按钮。

业务动作“停止任务”“结束录音”“暂停录音”不属于导航按钮。

## 4. 语音状态

```text
idle → listening → thinking → task/answered → error
```

Codex 模式：

```text
正在创建任务 → 已排队 → 正在连接 → 正在分析
→ 正在检查仓库 → 正在整理 → 完成/失败
```

Ollama 兼容模式：

```text
正在识别 → 回答完成 · 手表保持静音
```

## 5. 录音

- 首次点击开始采集，计时最多 60 秒。
- 暂停停止采集但保留计时与文本。
- 标记记录当前时间点。
- 结束停止计时、拼接 PCM、转写并创建任务。
- 离开页面清理计时器与麦克风资源。

## 6. Codex 轮询

- 创建任务后立即进入任务页。
- 每 1.5 秒轮询一次。
- 任务页和结果页可见时轮询。
- `onHide` 与离开页面停止轮询。
- `succeeded` / `failed` / `cancelled` 为终态。
- 完成后可进入结果页，完整文本可滚动查看。

## 7. 静音反馈

- 所有回答只显示文字。
- 设置页明确显示“始终静音 · 不影响睡眠”。
- 不使用扬声器图标表示播放，不提供声音开关。
- 触感反馈独立，不使用音频提示。

## 8. 错误

- 未配置令牌：提示填写 Codex 访问令牌。
- 401：令牌无效。
- 409：已有任务执行。
- 后端不可用：显示简短失败状态。
- 网络错误：保留识别文本，可重试或取消。
