# 页面与交互规格

## 1. 页面清单

| 页面/状态 | 入口 | 主要动作 | 结果 |
|---|---|---|---|
| 首页 | 初始页/返回 | 点击语音球 | 留在首页并激活语音动画 |
| 首页语音活动 | 首页语音球 | 麦克风、扬声器、结束、点击光球模拟一轮 | 状态变化、模拟回答、结束后回到首页空闲态 |
| 文字聊天 | 历史会话或新建对话 | 输入并发送 | 添加用户消息和模拟助手回复 |
| 历史记录 | 上下滑动或聊天返回 | 选择会话/新建 | 加载会话消息并进入文字聊天 |
| 录音 | 上下滑动 | 开始/停止录音 | 更新计时并进入转写页 |
| 转写 | 停止录音后 | 编辑、保存、复制、生成总结 | 更新文本并重算摘要 |
| 总结 | 转写页 | 复制摘要、重新录制、返回转写 | 复制文本或重启录音 |
| 设置 | 上下滑动 | 打开 API 设置 | 进入唯一设置子页 |
| 真实服务 | 设置页 | 输入服务地址、访问密钥、模型、连接测试 | 显示格式/连接反馈；密钥仅存当前会话 |

## 2. 手势

- 向上/向下：按预设顺序循环切换首页、录音、转写、总结、历史、设置、API 设置。
- 向右：回到上一层；无历史栈时回到首页。
- 首页语音活动中，上下滑动前会结束模拟语音状态，以避免语音计时器悬挂。
- 桌面预览支持 ↑ / ↓ 切换，`Esc` 返回。

## 3. 首页语音状态机

`idle → listening → thinking → speaking → listening`

- `idle`：显示语音球和开始提示。
- `listening`：显示呼吸光球、动态波形与计时。
- `thinking`：显示思考反馈；短暂延迟后进入 `speaking`。
- `speaking`：显示模拟回答；完成后返回 `listening`。
- `muted`：麦克风关闭时显示静音状态，用户触发一轮对话会收到提示。
- `end`：停止计时器与阶段定时器，回到首页空闲态。

## 4. 聊天行为

- 文字聊天始终采用普通消息气泡布局。
- 聊天输入为空时不发送。
- 发送后追加用户消息与本地模拟回复。
- 当前会话更新后同步回历史会话列表的数据模型。
- 聊天页麦克风入口回到首页并启动语音活动，而不是打开独立通话页。

## 5. 录音与摘要行为

- 录音计时器在录音页启动，在离开或停止后清理。
- 停止录音会写入演示转写文本并进入转写页。
- 保存编辑文本后重新生成摘要条目。
- 转写与摘要仍使用规则/演示逻辑；语音对话和文本聊天已接入真实本地服务。

## 6. 错误和反馈

使用轻量 toast 显示已复制、保存成功、格式错误、静音状态和演示限制。真实 API 接入后需增加超时、断网、权限拒绝、鉴权失败和限流状态。
