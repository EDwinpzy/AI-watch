# 页面与交互规格

## 1. 页面

| 页面 | 入口 | 主要动作 | 结果 |
|---|---|---|---|
| 首页 | 启动 | 开始对话 / 录音摘要 | 进入语音或录音 |
| 语音 | 首页 | 按住说话、松开或上滑结束 | 得到内置模型回答 |
| 语音回答 | 语音完成 | 复制、继续追问 | 进入聊天 |
| 录音摘要 | 首页 | 开始、暂停、标记、结束 | 转写并创建任务 |
| Codex 任务 | 语音/录音/文字 | 停止任务 | 取消后端任务 |
| 任务结果 | 任务成功 | 摘要/转写、复制、继续追问 | 复用文字或进入聊天 |
| 最近 | 主页上滑 | 新建对话、打开任务或会话 | 恢复聊天 |
| 文字对话 | 语音页/历史 | 输入并发送 | 创建文字任务或即时回答 |
| 设置 | 主页上滑 | 切换触感、界面风格 | 更新本机偏好 |

## 2. 主页面切换

```text
首页 ↔ 录音摘要 ↔ 最近 ↔ 设置
```

经典 Aurora 与 Apple Watch 圆环界面使用相同的四页结构。圆环界面的
“最近”同时列出 Codex 任务和本地会话，会话标题与状态在列表内滚动。
经典 Aurora 不渲染应用内时间、日期、信号或电池状态区，主页面只保留
一个主任务和最重要的操作。

首页固定只有两个主入口：开始对话、录音摘要。文字对话统一从
“最近 → 新建对话”进入，不作为首页第三个入口。

- 上下滑切换。
- 上下滑只记录目标页，手指抬起时立即切换；不做固定延迟，也不在切页后
  播放整页入场动画。
- 主页面左右滑不切页。
- 列表内部先滚动。只有手势开始时列表已经位于端点，下一次上/下手势
  才交给主菜单；同一手势内滚到端点不切页。
- “最近”列表总项在三条以内视为短列表；四条及以上优先滚动，不直接翻页。

## 3. 子页导航

- 子页左滑返回父级。
- 首页左右滑不执行动作。
- 系统返回手势在主页被拦截，任何应用内手势都不退出应用；只有手表
  右上实体表冠/Home 键可以退出。
- 不渲染返回、关闭或取消导航按钮。

业务动作“停止任务”“结束录音”“暂停录音”不属于导航按钮。

## 4. 语音状态

```text
idle → listening → thinking → task/answered → error
```

- 进入语音页只显示操作提示，不自动申请麦克风。
- 按住语音球开始采集；松开提交，或上滑至少 28 px 后松开结束。
- 触摸被系统中断时取消本次输入，不提交残缺音频。
- 经典页前台时，手表右下实体键会被厂商映射为 `KEYCODE_SOS`（265）；
  shell activity 同时兼容 `KEYCODE_BUTTON_9` / F26（196），并转为应用内
  语音事件。首次按下进入语音页并开始采集，再次按下结束并提交。600 ms
  防抖，并吞掉按键后系统合成的 DPAD_CENTER。
- 实体键入口只在手表前台工作时生效；触摸入口和实体键入口共享同一套
  录音、提交和状态机。

Codex 模式：

```text
正在创建任务 → 已排队 → 正在连接 → 正在分析
→ 正在检查仓库 → 正在整理 → 完成/失败
```

内置模型模式：

```text
正在识别 → 回答完成 · 手表保持静音
```

## 5. 录音

- 首次点击开始采集，计时最多 60 秒。
- 暂停停止采集但保留计时与文本。
- 标记记录当前时间点。
- 结束停止计时、拼接 PCM、转写并创建任务。
- 离开页面清理计时器与麦克风资源。

## 6. Codex 轮询

- 创建任务后立即进入任务页。
- 每 1.5 秒轮询一次。
- 任务页和结果页可见时轮询。
- `onHide` 与离开页面停止轮询。
- `succeeded` / `failed` / `cancelled` 为终态。
- 完成后可进入结果页，完整文本可滚动查看。

## 7. 静音反馈

- 所有回答只显示文字。
- 设置页明确显示“始终静音 · 不影响睡眠”。
- 不使用扬声器图标表示播放，不提供声音开关。
- 触感反馈独立，不使用音频提示。

## 8. 错误

- 内置模型不可用：提示检查局域网中继和服务配置。
- 401：令牌无效。
- 409：已有任务执行。
- 后端不可用：显示简短失败状态。
- 网络错误：保留识别文本，可重试或取消。

## 9. 圆环页差异

- 圆环页不显示服务地址、令牌或字段编辑入口，连接信息由本地构建配置注入。
- 两套界面的模型配置均在构建时注入，不提供后端切换入口。
- 录音摘要优先使用内置模型；Codex 任务接口仅作为服务端兼容能力保留。
- 任务结果页点按转写卡片进入编辑，保存后写回当前内存任务历史。
