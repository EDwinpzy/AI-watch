# NOVA 粒子语音助手原型

本地打开 index.html，或运行 python -m http.server 8791 --bind 127.0.0.1 后访问 http://127.0.0.1:8791。

界面包含首页、语音状态、会话列表/文字聊天、录音、转写编辑、摘要、偏好和服务表单。全部为本地模拟，无麦克风采集和 AI 请求。API Key 仅在内存，刷新后清空。

## 组件来源与边界
- 粒子球：改编自 amunozdev/voiceorbs 的 ParticlesOrb。保留 720 粒子球体分布、深度投影和连接环形过渡，移除 React 依赖并调整视觉参数。原始文件与 MIT 许可位于 vendor/。
- 基础控件视觉参考：皮卡啾⚡️发布的 Harmony OS 可穿戴设备，https://pixso.cn/community/file/S4sfYgulF2b2GMb0VX9GPQ ，资源页标注 CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。本原型将资源画布中可见的黑底列表、居中标题、蓝色强调及导航指示形式转换为 HTML/CSS；并非直接导出的 Pixso 组件实例，具体数值未取得源文件核对。
- 修改：业务文字、对话气泡、页面组合及适配为此项目实现。huawei-components.css 集中承载华为控件视觉映射，可在取得设计源文件后进一步校准。
- 未修改 api8-watch、entry 或签名文件；本原型不是可安装 HAP。
