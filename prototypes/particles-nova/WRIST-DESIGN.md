# 腕上布局修订依据

参考华为穿戴设计入口：https://developer.huawei.com/consumer/en/multidevice/wearables/get-started/
参考常规圆屏布局：https://developer.android.com/design/ui/wear/guides/foundations/common-layouts
参考单向纵向浏览：https://developer.android.google.cn/design/ui/wear/guides/m2-5/surfaces/apps-principles?hl=en

本轮重做：
- 首页仅语音主入口和功能列表入口。
- 功能、记录、设置使用纵向大列表；一屏主要显示约两至三项。
- 转写、摘要和会话用大字号纵向阅读，操作置于内容后。
- 聊天不再常驻键盘输入框，使用语音入口与快捷追问。
- 上下手势滚动列表，不再循环跳过全部页面；右滑按页面层级返回。
- 手机配套配置依然只是原型演示，无真实配对与请求。
- 控件为浏览器 CSS 预览，不能将其像素尺寸视为已验证的原生 dp。需手表实机核验手指触达、表冠行为和帧率。

组件基础继续参考用户指定的 Pixso 华为穿戴库，保留 VoiceOrbs 粒子视觉及原授权署名。
## 最新交互约定（替代此前菜单与手机配置方案）

- 手表端完成服务地址、密钥、模型配置，每屏一个可编辑字段；无手机配套弹窗。
- 无功能列表页，无手表内返回按钮。主屏顺序：首页→录音→会话→设置；左/上切下一屏，右/下切上一屏。
- 列表有可滚动内容时，上下优先滚动；到达边界后的下一次手势切换主屏。
- 子页右滑返回父页。字段右滑取消未保存编辑，保存写入当前内存。
- 桌面侧栏仅为预览跳转工具，不属于手表界面。
- 浏览器验证：左滑首页到录音、地址保存、密钥未保存时右滑取消并返回。
- 尚未验证手表原生输入法弹出后的布局、硬件手势冲突和原生 API 接入；当前输入控件为浏览器交互原型。

## 录音与整理页最新修订
- 转写与摘要合并为“录音整理”，同页用“摘要 / 原文”标签切换，录音完成后默认摘要。
- 原独立 #summary 链接兼容跳转至合并页；无独立摘要入口，无返回按钮。
- 录音改为连续三层程序波形、呼吸录制指示点；暂停保留时长并停止动态波形，继续重启，离开清理动画。
- 波形为程序演示，不表示真实声压，不申请麦克风权限。
- 浏览器验证：开始→暂停（00:11）→完成→合并整理页→原文标签切换。语法检查通过；原生设备帧率和录音链路未验证。
