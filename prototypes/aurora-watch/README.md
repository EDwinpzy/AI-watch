# Aurora Watch 交互原型

基于用户提供的 ChatGPT 手表概念图重设计的 466 × 466 圆屏 Web
交互原型。它用于视觉评审和交互演示，不是 HarmonyOS HAP，也不是
`api8-watch/` 的设备发布入口。

## 运行

在本目录启动静态服务：

```powershell
cd prototypes\aurora-watch
python -m http.server 8794 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8794/`。

视觉验收时可使用固定 466 × 466 表盘捕获模式：

```text
http://127.0.0.1:8794/?capture=1#home
```

页面支持左侧屏幕导轨、键盘 `←` / `→` / `Esc`，以及表盘区域手势。

## 表盘手势

- 在任意子页向右滑，按层级返回上一页；首页右滑不执行动作。
- 字段编辑浮层打开时，右滑先关闭浮层，不离开 API 配置页。
- 内容区保留纵向滚动；表盘内不显示返回、关闭或取消按钮。
- 桌面预览用 `→` 浏览下一屏，`←` 或 `Esc` 执行与右滑相同的逐级返回。

## 已覆盖流程

- 语音首页 → 聆听 → 回答 → 朗读、复制、反馈
- 录音入口 → 录音中 → 暂停/继续 → 实时转写 → 生成摘要 → 完成卡
- 摘要与转写标签切换、复制、继续追问
- 模型切换、官方/第三方 API 配置、字段编辑、连接测试和保存
- VPN 连接状态、节点选择与回显
- 推荐提问、图片生成、历史记录、设置项切换

交互使用本地模拟数据；麦克风、网络请求、ASR、TTS 和模型调用都没有接入。

## 文件

- `index.html`：页面骨架
- `styles.css`：圆屏、表壳、动效和响应式样式
- `app.js`：21 个屏幕、状态和交互
- `assets/`：从参考图裁出的展示素材
- `vendor/`：本地图标、品牌标志、国旗及各自许可证
- `design-qa.md`：与源图对比的视觉验收记录

## 素材与许可

`assets/` 中的主页能量球、旅行缩略图、图片生成示例和参考截图均从用户
提供的设计图裁切而来，仅用于本原型。界面图标来自 Phosphor Icons（MIT）；
OpenAI、Anthropic 和 Gemini 标志来自 Simple Icons（CC0 许可文件随目录
提供，品牌商标归各自权利人）；国旗素材为 CC0。字体使用系统字体栈，
未下载或再分发字体文件。

## 边界

- Previewer 和浏览器截图不等于 HarmonyOS 手表实机结果。
- 本原型不修改真实 HAP 页面、服务地址、签名或音频权限。
- 原型内 API Key 只显示掩码占位，不包含真实密钥。
- 浏览器剪贴板能力可用；录音计时、转写、摘要和连接测试均为演示状态。

视觉证据、视口尺寸和逐轮修正记录见 [design-qa.md](design-qa.md)。
