# Aurora Watch 交互原型

按用户提供的 ChatGPT 手表概念图重设计的 466 × 466 圆屏 Web 原型。
它用于视觉评审和交互走查，不是 HarmonyOS HAP，也不是发布入口。

## 运行

```powershell
cd prototypes\aurora-watch
python -m http.server 8794 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8794/`。固定 466 × 466 捕获模式：

```text
http://127.0.0.1:8794/?capture=1&freeze=1&screen=home#home
```

## 页面

当前保留 11 屏，全部对应实际产品流程：

1. 首页
2. 语音对话
3. 语音回答
4. 录音任务
5. Codex 任务执行
6. 任务结果
7. 最近任务
8. 文字对话
9. 设置
10. 服务配置
11. 字段编辑

已移除 VPN、图片生成、模型市场、推荐提问、TTS 开关和其他未使用功能。

## 手势

- 子页左滑按层级返回，首页左右滑不执行动作。
- 字段编辑左滑先关闭编辑层，不直接离开服务配置。
- 主页面上下滑切换；列表仅响应内部纵向滚动。
- 页面不显示返回、关闭或取消导航按钮。
- 桌面预览支持 `←` / `→` / `Esc` 浏览。

## 静音

原型不采集麦克风、不播放声音。设置页“手表声音”为固定只读行：

```text
始终静音 · 不影响睡眠
```

## 视觉基线

- 黑色玻璃底、青色能量球、双胶囊入口和低对比边框。
- 首页、录音、回答、任务、结果、历史、设置统一使用圆屏安全区。
- 聊天底栏收窄并向内移动，避免圆形边缘裁切。
- 图标来自 Phosphor Icons（MIT），品牌标志来自 Simple Icons（CC0）。
- 主页能量球使用用户参考图裁切后的透明底位图。

浏览器截图只用于视觉验收，不替代 HarmonyOS 真机结果。
